# حلقة الأترجة الافتراضية

برنامج متابعة حلقة قرآنية: صفحة للطالبة فيها مقدار اليوم والتقييم والتفسير
والتكاليف، ولوحة للمعلمة فيها الحضور والتقرير الأسبوعي وعجلة الحظ.

## الروابط

| | |
|---|---|
| الموقع (Firebase) | https://atheer-aee17.web.app |
| الموقع (GitHub Pages) | https://ahmadabd733-bot.github.io/atheer/ — يتوقف إن صار المستودع خاصًّا |
| لوحة Firebase | https://console.firebase.google.com/project/atheer-aee17 |

الموقعان يقدّمان الملفات نفسها ويتصلان بقاعدة البيانات نفسها.

## طريقة الدخول

**للطالبة:** تفتح https://atheer-aee17.web.app ← تُدخل كلمة مرور الحلقة ←
تختار اسمها من قائمة الطالبات. لا يُطلب منها شيء بعدها على الجهاز نفسه.

ثلاث بوابات في البرنامج:

1. **كلمة مرور الحلقة** — أول شاشة على كل جهاز. البريد ثابت في الشفرة
   (`halaqa@atheer-aee17.firebaseapp.com`) فلا يُطلب، وتُدخَل كلمة المرور وحدها.
   بعدها يُحفَظ رمز التجديد في المتصفح فلا تُطلب مرة أخرى على ذلك الجهاز.
   كلمة المرور **ليست في المستودع**، وهي في حساب Firebase Authentication:
   https://console.firebase.google.com/project/atheer-aee17/authentication/users

2. **رمز الحلقة** — مضبوط مسبقًا في البرنامج فلا يُطلب عادةً. تظهر بوابته
   فقط إن فُكَّ الربط من (صفحة المعلمة ← إعدادات صفحة الطالبة ← فكّ الربط).

3. **حساب المعلمة** — زر «صفحة المعلمة» يطلب كلمة مرور المعلمة، وبريده ثابت
   في الشفرة (`teacher@atheer-aee17.firebaseapp.com`). ليس رمزًا يُقارَن في
   المتصفح بل حساب مستقلّ تعرفه قواعد قاعدة البيانات، فالمنع يقع على الخادم لا
   في الصفحة. للخروج منه على جهاز مشترك: صفحة المعلمة ← إعدادات صفحة الطالبة ←
   «خروج من حساب المعلمة».
   يبقى الرمز الرقمي القديم للوضع المحلي وحده (بلا مزامنة)، حيث لا خادم يمنع.

كلمة مرور الحلقة وكلمة مرور المعلمة حسابان مستقلّان: الأول يفتح البيانات
للقراءة والمشاركة، والثاني يفتح التحكم.

## الصلاحيات

`database.rules.json` يفصل ما يستطيعه حساب الحلقة عمّا يستطيعه حساب المعلمة:

| المسار | حساب الحلقة (الطالبات) | حساب المعلمة |
|---|---|---|
| كل شيء | قراءة | قراءة |
| `halaqa/settings` و`halaqa/roster` | — | كتابة |
| `days/<التاريخ>` (الحضور والتقييم والملاحظات) | — | كتابة |
| `days/<التاريخ>/records/<الطالبة>/tasks` | كتابة | كتابة |
| `benefits/<المعرّف>` | كتابة بحالة `pending` أو حذف | كتابة بأي حالة |
| `meta/rev` (ختم المزامنة) | كتابة | كتابة |

لذلك تكتب صفحة الطالبة عقدة `tasks` وحدها لا وثيقة اليوم كاملة، وإلا رفضتها
القواعد. الاعتماد الحقيقي على القواعد لا على إخفاء الأزرار في الواجهة.

**ما لا تحميه هذه القواعد:** الطالبات يتشاركن حسابًا واحدًا، فلا تفرّق القواعد
بين طالبة وأخرى. تستطيع الطالبة — بأدوات المطوّر — أن تعلّم تكاليف زميلتها أو
تحذف فائدتها. الحماية هنا بين *الطالبات* و*المعلمة*، لا بين طالبة وأخرى؛
ولفصلهنّ يلزم حساب لكلّ طالبة.

## إنشاء حساب المعلمة

خطوة يدويّة تُعمل مرّة واحدة، **قبل** دمج هذا العمل في `main`:

1. افتحي https://console.firebase.google.com/project/atheer-aee17/authentication/users
2. Add user ← البريد `teacher@atheer-aee17.firebaseapp.com` ← كلمة مرور قويّة.
3. ادمجي في `main` (ينشر السير التلقائي القواعد الجديدة)، أو انشري يدويًّا:
   `firebase deploy --only database,hosting`
4. على جهاز المعلمة: صفحة المعلمة ← أدخلي كلمة مرور المعلمة.

⚠️ **الترتيب مهمّ.** لو نُشرت القواعد قبل إنشاء الحساب لتعطّل حفظ الإعدادات
والحضور عند المعلمة، لأنّ حسابها القديم (حساب الحلقة) لم يعد يملك الكتابة.
وإن تغيّر البريد فغيّريه في `database.rules.json` و`utrujjah-halaqa.html` معًا.

## بنية المشروع

```
utrujjah-halaqa.html   البرنامج كاملًا: الواجهة والمنطق وتفسير السعدي المضمّن
index.html             تحويل إلى البرنامج
write/                 49 صورة لأوجه المصحف (الأنعام والأعراف، الصفحات 128-176)
مصحف صوتي/             تلاوة الأوجه — محلية فقط، لا تُرفع (تُبثّ من archive.org)
تفسير سورة *.txt       مصدر التفسير الذي بُني منه المضمَّن — لا يُرفع
firebase.json          إعداد الاستضافة وقواعد القاعدة
database.rules.json    الصلاحيات: القراءة بحساب الحلقة، والكتابة موزّعة بينه وبين المعلمة
```

## من المحلي إلى السحابي

```bash
# 1) الشفرة والصور إلى GitHub (ينشر تلقائيًا على GitHub Pages)
git add -A && git commit -m "..." && git push

# 2) الموقع إلى استضافة Firebase
firebase deploy --only hosting

# 3) قواعد قاعدة البيانات بعد تعديل database.rules.json
firebase deploy --only database

# أو الاثنان معًا
firebase deploy
```

## قاعدة البيانات

Firebase Realtime Database على `atheer-aee17-default-rtdb.firebaseio.com`.
البيانات تحت `utrujjah/<رمز الحلقة>/` وتنقسم إلى `halaqa/settings`
و`halaqa/roster` و`days/<التاريخ>` و`benefits/<المعرّف>`.

القواعد تشترط تسجيل الدخول، فلا يقرأ أحد بلا حساب. والكتابة مقسومة بين
حساب الحلقة وحساب المعلمة — انظري «الصلاحيات» أعلاه.
الطالبة تُدخل كلمة المرور مرة واحدة على جهازها.

## النشر التلقائي

`.github/workflows/deploy.yml` ينشر إلى Firebase عند كل دفع إلى main،
لكنه **يتخطّى النشر بهدوء** ما لم يُضبط سرّ `FIREBASE_SERVICE_ACCOUNT`
في إعدادات المستودع (Settings ← Secrets and variables ← Actions).
قيمته ملف JSON لحساب خدمة له دورا `firebasehosting.admin`
و`firebasedatabase.admin`.
